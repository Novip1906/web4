### Отчет об исправлениях

В соответствии с требованиями преподавателя были внесены следующие изменения:

1. **Удаление подложки**: Из разделов "About you" и "Цель работы" была убрана фоновая подложка (класс `.card` заменен на `.plain-container`), чтобы контент располагался непосредственно на фоне страницы.
   ```css
   /* Было */
   <div class="card">...</div>
   
   /* Стало */
   <div class="plain-container">...</div>
   ```

2. **Анимация кнопок калькулятора**: Добавлено увеличение кнопок при наведении курсора (`hover`) для улучшения интерактивности.
   ```css
   .my-btn:hover {
     background: var(--btn-hover);
     transform: scale(1.1);
     z-index: 10;
     position: relative;
   }
   ```

3. **Увеличение шрифта**: В разделе "About You" увеличен размер шрифта для лучшей читаемости личных данных.
   ```css
   .author-info p {
     font-size: 1.2rem;
     line-height: 1.6;
   }
   ```
